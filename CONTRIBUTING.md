# Contributing

Thanks for taking a look. Small fixes are welcome as pull requests. For anything larger, please open an issue first so we can agree on it.

- By contributing code you agree that it is licensed under the AGPL-3.0, and that the maintainer may also distribute it under other terms, including commercial licenses.
- Please do not add third-party code or assets without saying where they come from and under what license.
- Art, fonts and the project name are not open to reuse (see `ASSETS-LICENSE.md`). Art contributions need explicit permission first.
- Run `npm test` against `wrangler dev` before sending a change (see `README.md`).
