Privacy & data

I keep your names, animals and address, when each note was made and by whom, and scrambled versions of your passcode and network address. Your notes, drawings and drafts are locked in your browser with your passcode before they are sent, so I can't read them. The note you send with a request is the one thing I can read.

The honest limits
  • Anyone with the address and passcode can read the wall. A short passcode can be guessed by someone holding the database, so a longer one is safer. The dice button makes one.
  • A lost passcode can't be recovered, and neither can the notes locked with it.
  • Cloudflare, which hosts the site, sees network traffic and keeps request logs.
  • The pages are code I serve, so a changed version could capture passcodes. The code is public so it can be checked.
  • Walls made before locking existed are locked the first time someone opens them.
